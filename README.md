# Administrative Audit Platform

MVP administrativo para demonstrar RBAC, multi-tenant, autorização por recurso,
auditoria imutável e dashboard operacional.

## Domínios

- usuários, perfis e permissões;
- tenants e escopo de dados;
- ações administrativas com ator, recurso, resultado e correlação;
- consulta paginada de auditoria.

Veja [docs/api.md](docs/api.md) e [docs/security.md](docs/security.md).
